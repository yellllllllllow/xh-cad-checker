# 图样编号规则（本项目适用）

来源：企业《图样编号规则》图框说明。本 checker 默认按以下规则解析 `A(部件) / B(加工类型) / C(流水号)`。

## 编号结构

```
<产品代号> . <A 项> . <B 项> - <C 项流水号> [ 版次] [ 名称]
```

示例：`XH042601.03.01-001 A1 方管焊接架`
- `XH042601.03` — 产品代号（产品类型 + 产品序号）
- `03` — A 项（机器部件类型）
- `01` — B 项（加工类型）
- `001` — C 项（该部件下具体零件流水号）
- `A1` — 版次（可选）
- `方管焊接架` — 零件名称

> 子装配允许多级流水号，如 `XH042601.03.01-001-002` 表示 C=001 号零件下的第 002 子件。
> 父子件（如 `…-001` 与 `…-001-002`）属于正常层级关系，本 checker **不会**判定为重号。

## A 项（机器部件类型）

| 代码 | 含义 |
|---|---|
| 01 | 小车组件 |
| 02 | 主控门组件 |
| 03 | 柜体组件 |
| 04 | 货道组件 |
| 05 | 层架组件 |
| 06 | 玻璃门组件 |

## B 项（加工类型）

| 代码 | 含义 |
|---|---|
| 01 | 钣金件 |
| 02 | 机加工件 |
| 03 | 塑胶件 |
| 04 | 电气件 |
| 05 | 标准件 |
| 06 | 外购定制件 |
| 07 | 其它 |

## C 项（流水号）

- 从 `001` 起递增，同一 (A,B) 组内的具体零件序号。
- 断号分析会列出 `1..max` 之间缺失的编号段，用于判断是否有漏缺或预留空位。

## 自定义

若其他项目采用不同的 A/B 映射，运行脚本时用 `--a-map` / `--b-map` 传入 JSON 覆盖默认映射即可：

```bash
python check_archive.py --dir <目录> \
  --a-map '{"01":"组件A","02":"组件B"}' \
  --b-map '{"01":"钣金","02":"机加"}'
```

若文件命名不符合 `<前缀>.AA.BB-C` 模式（如总装 `03-01 升降交接台`、外购件 `TXCJ-H6-2040-L815` 未编号），
脚本会将其归入「未识别」清单，不影响完整性检查（缺 stp/pdf/dwg 仍照常统计）。
